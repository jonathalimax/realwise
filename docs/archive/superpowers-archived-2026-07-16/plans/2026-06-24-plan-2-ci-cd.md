# Plan 2: CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automate build, Docker image publishing, and Coolify deployment for all three apps (web, admin, api) on every push to `main` (production) and `develop` (staging).

**Architecture:** GitHub Actions builds each app, packages it into a Docker image, pushes to GHCR with immutable SHA tags plus a mutable environment tag (`latest` / `staging`), then triggers Coolify via its REST API to pull and redeploy the new image. A pre-deploy SSH step runs the PostgreSQL backup script before every production API deploy.

**Tech Stack:** GitHub Actions, GHCR (`ghcr.io`), Docker (multi-stage builds), nginx:alpine (web/admin static serving), Coolify API v1, `appleboy/ssh-action` for SSH.

## Global Constraints

- pnpm 9.15.0 — all install steps must use `corepack enable && corepack prepare pnpm@9.15.0 --activate`
- Node 22 — all `node:` images and Actions runner setup must use Node 22
- Build context for all `docker build` calls is the monorepo root (`.`) — Dockerfiles reference root-relative paths
- Monorepo root package filter syntax: `pnpm --filter @realwise/<app> <script>`
- Image registry: `ghcr.io/jonathalima/realwise-<app>`
- Production image tag: `latest` + `sha-${{ github.sha }}` (first 7 chars)
- Staging image tag: `staging` + `sha-${{ github.sha }}` (first 7 chars)
- Coolify API endpoint pattern: `POST $COOLIFY_BASE_URL/api/v1/deploy?uuid=UUID&force=false`
- Branch strategy: `main` → production, `develop` → staging, `feature/*` → PR validation only
- All secrets live in GitHub repository secrets — never hardcoded

- [ ] **Step 2: Create `apps/web/Dockerfile`**

```dockerfile
FROM node:22-alpine AS builder
WORKDIR /app
COPY package.json pnpm-lock.yaml pnpm-workspace.yaml ./
COPY packages/types/package.json ./packages/types/
COPY apps/web/package.json ./apps/web/

COPY apps/web/ ./apps/web/
RUN pnpm --filter @realwise/web build

FROM nginx:alpine AS runner
COPY --from=builder /app/apps/web/dist /usr/share/nginx/html
COPY apps/web/nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

## Task 3: `.github/workflows/web.yml`

**Files:**
- Create: `.github/workflows/web.yml`

**Interfaces:**
- Consumes: `apps/web/Dockerfile` from Task 1; GitHub Secrets from the prerequisites section
- Produces: GHCR images `ghcr.io/jonathalima/realwise-web:latest` (on main) and `ghcr.io/jonathalima/realwise-web:staging` (on develop); Coolify deploy triggered

- [ ] **Step 1: Create `.github/workflows/web.yml`**

```yaml
name: Web

on:
  push:
    branches: [main, develop]
    paths:
      - 'apps/web/**'
      - 'packages/types/**'
      - '.github/workflows/web.yml'
  pull_request:
    branches: [main, develop]
    paths:
      - 'apps/web/**'
      - 'packages/types/**'

jobs:
  validate:
    name: Lint & Build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: '22'
          cache: 'pnpm'

      - name: Install pnpm
        run: corepack enable && corepack prepare pnpm@9.15.0 --activate

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Lint
        run: pnpm --filter @realwise/web lint

      - name: Build
        run: pnpm --filter @realwise/web build

  deploy:
    name: Build & Deploy
    runs-on: ubuntu-latest
    needs: validate
    if: github.ref == 'refs/heads/main' || github.ref == 'refs/heads/develop'
    permissions:
      contents: read
      packages: write
    steps:
      - uses: actions/checkout@v4

      - name: Set image metadata
        id: meta
        run: |
          SHORT_SHA=${GITHUB_SHA::7}
          if [ "$GITHUB_REF" = "refs/heads/main" ]; then
            echo "env_tag=latest" >> $GITHUB_OUTPUT
            echo "coolify_uuid=${{ secrets.COOLIFY_WEB_PROD_UUID }}" >> $GITHUB_OUTPUT
          else
            echo "env_tag=staging" >> $GITHUB_OUTPUT
            echo "coolify_uuid=${{ secrets.COOLIFY_WEB_STAGING_UUID }}" >> $GITHUB_OUTPUT
          fi
          echo "sha_tag=sha-${SHORT_SHA}" >> $GITHUB_OUTPUT
          echo "image=ghcr.io/jonathalima/realwise-web" >> $GITHUB_OUTPUT

      - name: Log in to GHCR
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Build and push Docker image
        uses: docker/build-push-action@v5
        with:
          context: .
          file: apps/web/Dockerfile
          push: true
          tags: |
            ${{ steps.meta.outputs.image }}:${{ steps.meta.outputs.env_tag }}
            ${{ steps.meta.outputs.image }}:${{ steps.meta.outputs.sha_tag }}

      - name: Trigger Coolify deploy
        run: |
          curl -s -f -X POST \
            "${{ secrets.COOLIFY_BASE_URL }}/api/v1/deploy?uuid=${{ steps.meta.outputs.coolify_uuid }}&force=false" \
            -H "Authorization: Bearer ${{ secrets.COOLIFY_API_TOKEN }}" \
            -H "Content-Type: application/json"
```

# Rollback a Production Deploy

## Option A — Coolify UI (< 2 minutes)

1. Open Coolify → select the app (realwise-web, realwise-admin, or realwise-api)
2. Click **Deployments** tab
3. Find the last successful deploy — click **Redeploy**

Coolify re-runs that deployment with the same image tag it used previously.

## Option B — Re-trigger previous GitHub Actions run (< 5 minutes)

1. Open GitHub Actions → find the last successful workflow run before the bad one
2. Click **Re-run all jobs**
3. This pushes the previous commit's `sha-XXXXXXX` image and fires Coolify webhook

## Option C — Manual image override (fastest for API)

If you need a specific commit's image:

```bash
# SSH into VPS
ssh root@62.238.45.195

# Find the SHA tag you want from GHCR (check GitHub Packages UI)
# Tell Coolify to use it — or run directly:
docker pull ghcr.io/jonathalima/realwise-api:sha-abc1234
docker tag ghcr.io/jonathalima/realwise-api:sha-abc1234 ghcr.io/jonathalima/realwise-api:latest
```

Then trigger Coolify redeploy from UI.
